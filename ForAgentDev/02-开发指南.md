## 3.1 连接配置（连真实 Multica）

所有 fanout 命令都支持以下全局连接配置，优先级 **命令行 > 环境变量 > 配置文件**：

```bash
# 生成配置文件模板
fanout config --init          # → 生成 ./multica.config.json

# 查看当前生效配置
fanout config
fanout config --json
```

配置文件 `multica.config.json`（**已被 gitignore，不提交**；模板提交为 `multica.config.example.json`）：

```json
{
  "multicaBin": "multica",
  "profile": "",
  "workspaceId": "",
  "serverUrl": ""
}
```

| 字段 | 说明 | 获取方式 |
| --- | --- | --- |
| `multicaBin` | multica 命令，支持带前缀 | 一般默认 `multica` |
| `profile` | multica CLI profile 名 | `multica config show`；自托管多环境时用 `--profile` 隔离 |
| `workspaceId` | 工作区 ID | `multica workspace list --output json` |
| `serverUrl` | 自托管服务地址 | 部署 Multica 时的 API 地址；Multica Cloud 留空 |

**token 安全**：令牌不写入配置文件，统一用 `multica login` 登录（或 `multica setup self-host`）。配置文件泄露最多暴露内部地址，不暴露凭证。

环境变量等价项：`MULTICA_BIN` / `MULTICA_PROFILE` / `MULTICA_WORKSPACE_ID` / `MULTICA_SERVER_URL`。

```bash
# 示例：命令行覆盖
fanout dispatch --title "x" --agents a,b --workspace-id ws-123 --profile staging
```

## 4. 无真实 Multica 环境时的开发

内置 fake CLI mock，可完整跑通「派发 → 看板 → 聚合」流程：

```bash
# Windows Git Bash（路径需为 Windows 格式，pwd -W 转换）
export FAKE_STATE_FILE=./.fake-multica-state.json
export MULTICA_BIN="node $(pwd -W)/test/fake-multica.mjs"

node bin/fanout.js dispatch --title "测试" --description "背景" \
  --agents "codex,claude,gemini,hermes,opencode,cursor"
node bin/fanout.js status MUL-100
```

> 机制：`MULTICA_BIN` 环境变量可替换 multica 命令（支持带参数前缀），fake 脚本模拟
> `agent list / issue create / children / comment` 等命令并持久化状态到 JSON 文件。

## 5. 测试约定

- 测试文件位于 `test/`，命名 `*.test.mjs`；
- 集成测试通过 `MULTICA_BIN` 注入 fake，**不得依赖真实 Multica 环境**；
- 新增功能必须配套测试，`npm test` 全绿是合并前提；
- fake 命令行为变更时，同步维护 `test/fake-multica.mjs` 与 `test/fanout.test.mjs`。

## 6. 故障排查

| 现象 | 处理 |
| --- | --- |
| `未检测到 multica CLI` | 安装 multica（见项目 README）或设置 `MULTICA_BIN` 指向 mock |
| Windows 下 fake 路径报错 | `MULTICA_BIN` 内路径必须是 Windows 格式（`C:/...`），用 `pwd -W` 获取 |
| `命令失败 (1)：multica issue ...` | 用 `multica <cmd> --help` 核对参数；CLI 版本差异以 `--help` 为准 |
| 评论中文乱码 | 长内容一律走 `--content-stdin` / `--description-stdin`，避免 shell 转义 |
