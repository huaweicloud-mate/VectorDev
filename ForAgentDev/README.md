# ForAgentDev — Agent 开发标准化文档库

> 本目录是 VectorDev 仓库的**标准化文档库**，面向所有进入开发的开发者（人类与 AI Agent）。
> 目标是：任何开发者（尤其是 Agent）都能凭文档**独立、一致、低冲突**地完成开发任务。

## 使用方式

- **新开发者入场**：按编号顺序阅读 01 → 05；
- **开发中查询**：按主题跳读（见下方索引）；
- **贡献文档**：任何改动同步更新对应文档；新增规范先讨论再落文档。

## 文档维护约定

1. **单一事实源**：本目录是规范唯一权威，仓库根 README / AGENTS.md 只做索引；
2. **同步更新**：代码行为变更 → 必须同步更新受影响文档（合并前由审查者检查）；
3. **可执行**：所有命令给出可复制版本，所有约定给出「做 / 不做」的明确判断；
4. **版本关联**：重大变更在文档头部记录「最后更新日期 + 关联 Issue/PR」。
